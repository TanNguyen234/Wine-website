## Nguyên tắc & Ràng buộc Bất biến (Hard Constraints)

1. **Giữ nguyên Thymeleaf SSR**: Không tách React/Next.js/Vue SPA. Toàn bộ giao diện User / Admin / Shipper được tái cấu trúc bằng CSS Design Tokens (`@layer`), native Web APIs (`<dialog>`, `popover`, `@container`, `@view-transition`), bespoke SVG và modular ES Modules.
2. **Bảo vệ tuyệt đối cơ sở dữ liệu SQL Server**:
   - Không `DROP TABLE`, không `DROP COLUMN`, không `ALTER COLUMN` làm hỏng hoặc mất dữ liệu hiện hữu.
   - `spring.jpa.hibernate.ddl-auto=validate` phải pass ở mọi Wave.
   - Mọi bảng/cột mới đưa vào **`V17`** (hoàn toàn additive, cột mới ở bảng cũ đều cho phép `NULL` hoặc có `DEFAULT`). Riêng nâng độ chính xác tiền tệ `DECIMAL(10,2)` -> `DECIMAL(18,2)` được tách vào **`V18`** và phải đồng bộ cùng commit với `@Column(precision = 18, scale = 2)` trên Entity để Hibernate `validate` pass ngay lập tức.
3. **Production Real-Only**: Tuyệt đối không dùng mock/fake trong runtime; mọi lỗi phải ném exception phân loại rõ ràng; test kiểm chứng bằng `./mvnw compile -DskipTests`, JUnit thực tế và Playwright/CDP trên browser thật.
4. **Cổng phê duyệt (`<HARD-GATE>`)**: Không sửa source code, template hay migration trước khi người dùng duyệt bản Super Plan này.

### 1.2. Kiến trúc Design System V3 ("Maison de Vins") & Chuẩn Hóa Hiện Đại

1. **Tách Bundle theo Route + `@layer`**:
   - Loại bỏ `app.css` và `sw-redesign.css` đơn khối; gỡ bỏ Bootstrap 5.3 và FontAwesome 6.5.1 khỏi Storefront & Shipper (Admin giữ hoặc thay hoàn toàn bảng/toast bằng CSS layer + native `<dialog>`).
   - Tổ chức CSS theo chuẩn `@layer reset, tokens, base, layout, components, utilities, themes` (tuyệt đối **không** dùng global `*` reset):
     - `/css/tokens.css`: bảng màu ngữ nghĩa (`--surface-*`, `--text-*`, `--border-*`, `--accent-*`), typography scale, radius, elevation, motion tokens.
     - `/css/storefront.css`, `/css/admin.css`, `/css/shipper.css`: chỉ nạp đúng CSS của phân hệ đó.
2. **Dual-Theme `light dark` (Luxury Dark Cellar + Warm Ivory)**:
   - Không hardcode một `color-scheme` duy nhất làm mặc định gốc; `:root` khai báo `color-scheme: light dark;` kèm inline FOUC-prevention script trong `<head>` đọc `localStorage` + `prefers-color-scheme` và gắn `data-theme="cellar" | "ivory"` + `<meta name="color-scheme">`.
   - **Storefront mặc định Dark Cellar** (đúng `AGENTS.md`):
     - Surface: `#0c0a08` (noir cellar) · `#171310` (card elevated) · `#221b17` (modal/popover).
     - Accents: `#8b1a1a` / `#a83030` (crimson burgundy) · `#c9a84c` / `#e2be72` (warm champagne gold — tinh chỉnh sắc độ đạt **>= 4.5:1** trên nền `#0c0a08` và dùng biến `--accent-gold-ink` tối hơn khi ở chế độ Ivory).
     - Ink: `#f0e8da` (primary ivory) · `#bfb3a2` (secondary >= 4.5:1).
   - **Chế độ Light Ivory** (`[data-theme="ivory"]`): `#f7f4ed` nền kem rượu, `#fffdf8` card, `#7d1b29` crimson, `#1d1815` ink, gold text tối (`#7a5b2b`) đạt >= 4.5:1 trên nền sáng.
   - **Xử lý ảnh chai rượu đa theme**: bỏ `mix-blend-mode: multiply` (`sw-redesign.css:3245`, vốn làm chai biến mất trên nền đen); thay bằng khung spotlight nền ấm radial (`radial-gradient` tinh tế) + drop-shadow mềm.
3. **Typography & Bespoke Wine SVG System**:
   - Chỉ nạp 2 family chính (`Playfair Display` cho tiêu đề biên tập + `Plus Jakarta Sans` cho UI/bảng dữ liệu, thêm `JetBrains Mono` dạng `tabular-nums` cho mã OTP, giá tiền VND, SKU), subset `vietnamese,latin`.
   - Tạo `templates/fragments/icons.html` chứa bộ SVG 1.5px bespoke (`wine-glass`, `decanter`, `oak-barrel`, `wax-seal`, `grape-cluster`, `verified-bottle`, `warehouse-map`, `cod-wallet`) để thay toàn bộ glyph Unicode thô (`×`, `★`, `⌄`, `←`, `→`).

### Modern Web Guidance (Các chuẩn trình duyệt bắt buộc tuân thủ trong Wave 3)

- **`dialog`**: `"Use the native <dialog> element for modal and non-modal dialogs."` và `"MANDATORY (both rules): without them, scrolling over the backdrop or inside the dialog scrolls the page behind it"` (áp dụng `dialog:modal { overscroll-behavior: contain; }` & `dialog::backdrop { overflow: hidden; overscroll-behavior: contain; }`).
- **`light-dismiss-a-dialog`**: `"MANDATORY: Use closedby=\"any\" to enable light-dismiss behavior"` và `"MANDATORY: For browsers that do not yet support closedby, you must implement a fallback for light-dismiss..."` (dùng trong `toast-dialog.js`).
- **`dark-mode-toggle`**: `"DO NOT hardcode color-scheme: light or color-scheme: dark as the root default; the base declaration MUST stay light dark."` (kết hợp inline `<script>` chống FOUC cập nhật `<meta name="color-scheme">`).
- **`cross-document-transitions`**: `"Both the source and destination pages must opt-in to view transitions"` (bọc `@view-transition { navigation: auto; }` trong `@media (prefers-reduced-motion: no-preference)`).
- **`responsive-table`**: `"Use @container queries instead of @media queries."` và `"MANDATORY: Hide column header from layout and screen readers. display: none"` cho bảng Admin/Giỏ hàng dưới `@container (width < 600px)`.
- **`sms-otp-form`**: `"Do not split digits across multiple <input> elements: Multi-box OTP patterns (six separate maxlength=\"1\" inputs) break native autocomplete=\"one-time-code\" autofill in many browsers, hinder copy-pasting, and complicate screen reader navigation. If a segmented visual design is required, style a single <input> with letter-spacing and a monospace font."`
- **`css`**: `"Use cascade layers (@layer) to define explicit priority zones"` và `"DO NOT use global resets (styles on *)"`.
- **`validate-input-after-interaction`**: `"The :user-invalid pseudo-class allows you to defer the error state until the user has \"committed\" to a value"`.
